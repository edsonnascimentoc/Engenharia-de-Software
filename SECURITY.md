# Política de segurança

## Reporte privado

Não abra uma issue pública para relatar uma vulnerabilidade. Envie o relato
privadamente pelo [formulário de reporte de vulnerabilidade do GitHub](https://github.com/edsonnascimentoc/Engenharia-de-Software/security/advisories/new).
Esse canal permite que mantenedores e o relator discutam o problema antes de
qualquer divulgação pública. Se o formulário não estiver disponível, contate o
responsável pelo repositório pelo [perfil GitHub de @edsonnascimentoc](https://github.com/edsonnascimentoc)
e solicite um canal privado; não publique detalhes técnicos no contato inicial.

Inclua no relato, quando possível:

- componente, arquivo ou workflow afetado e versão/commit;
- passos para reproduzir e impacto observado;
- versão corrigida ou mitigação sugerida, se conhecida.

## Escopo

São aceitos relatos sobre vulnerabilidades reproduzíveis no código e nos
scripts mantidos neste repositório, workflows e configuração de GitHub Actions,
dependências declaradas, ou exposição de segredos causada por esses componentes.
Relatos devem demonstrar um impacto de segurança concreto. Problemas em serviços
de terceiros, contas pessoais, configurações locais fora deste repositório e
achados sem impacto explorável não são cobertos por esta política; encaminhe-os
ao responsável pelo sistema correspondente.

Preserve a confidencialidade dos dados e evite acessar, alterar ou exfiltrar
informações de terceiros durante a investigação. O responsável confirmará o
recebimento e coordenará a análise e a divulgação com o relator.
